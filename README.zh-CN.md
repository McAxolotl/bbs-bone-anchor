# BBS 骨骼 Anchor

[English](README.md) | **简体中文** · v1.0.1

BBS FS 的客户端 Fabric 附属模组，为**模型形态（Model Form）**加入逐骨骼、跨模型 **Anchor** 绑定。模型中的单根骨骼可以跟随另一个回放（Replay）的形态、骨骼或身体附件。

## 功能

- 逐骨骼 Anchor 轨道，折叠在整体 Anchor 下方。
- 跨模型目标，复用原生 Anchor 的目标拾取、继承和保持变换编辑。
- 将身体附件转换为回放，并把原来的 BodyPart 父子关系表达为回放根形态上的 Anchor 关键帧；支持转换和复制。
- 支持 IK 目标、骨骼约束、物理、镜像缩放和焊接渲染。
- 多个回放共用同一模型资源时使用独立骨架。
- 时间轴和形态的**筛选轨道**窗口保持相同的骨骼层级顺序。
- Anchor 轨道右键菜单提供仅当前会话有效的**只显示已绑定骨骼**过滤。
- 支持 BBS FS 全部 19 种语言。

## 环境要求

- Minecraft 1.20.1
- Fabric Loader 0.16.14+
- Fabric API
- BBS FS 2.7
- Java 17+

## 使用方法

1. 在 BBS 回放编辑器中打开影片。
2. 展开根模型形态的 **Anchor** 轨道。
3. 打开逐骨骼轨道，通过原生 Anchor 编辑器选择目标。
4. 右键整体 Anchor 或骨骼轨道，可切换**只显示已绑定骨骼**。
5. 打开回放编辑器的**身体附件**树并右键身体附件：
   - **转换为回放**：把嵌套形态及其属性轨道移入新回放，移除原 BodyPart；当前影片中指向该附件或其子附件的已有 Anchor 引用会自动重定向到新回放。
   - **复制为回放**：创建新回放，保留原 BodyPart 及其轨道；已有 Anchor 引用仍指向原附件，不会改为引用副本。
   - 两种操作都会在新回放根形态上生成 Anchor 关键帧，目标指向原骨骼或所属形态，局部变换保留采样时的 BodyPart 父级帧。悬停菜单项可查看引用关系的处理说明。

逐骨骼数据内部使用 `anchor:<骨骼名>`，界面只显示原始骨骼名。

## 限制

- 逐骨骼 Anchor 仅适用于根模型形态。
- 身体附件转换要求源回放使用绝对坐标，因为生成的 Anchor 会链接到该回放。
- 转换记录当前游标处的 BodyPart 父级帧，并不烘焙整段影片。BodyPart 的部分继承行为只会采样到这个帧中，不会在转换后动态复现；祖先形态中驱动该子树的动画状态不会迁移到新回放。
- 后续重定向使用原生 Anchor 编辑器的可选 **Keep transform** 设置。局部变换包含非有限值、奇异矩阵或剪切时，会在修改源附件前拒绝转换。
- 转换迁移形态属性轨道（包括带形态路径的未知轨道），并在创建新关键帧前清理原先未生效的根 Anchor 设置。
- 新回放复制分类、启用状态、阴影、循环和源回放关键帧；不迁移标签、名称标签、动作片段、Actor/第一人称标志及 BodyPart 的 `useTarget` 包装行为。
- 受活动 IK、物理或约束直接控制的骨骼不能作为 Anchor 源。
- CEM 驱动的骨骼不能作为 Anchor 源。
- 绝对坐标与相对坐标回放之间不能绑定。

## 构建

```bash
./gradlew clean check build
./gradlew smokeTest
./gradlew smokeJar remapSmokeJar
```

`check` 会编译模组、运行无需启动游戏的用例，并审计项目与打包产物：mixin 注册、全部 19 种本地化、Fabric 元数据、源码约定与冒烟接线。`smokeTest` 会启动开发客户端跑游戏内用例，报告与期望计数不符即失败；`smokeJar`/`remapSmokeJar` 生成用于生产实例验证的冒烟 jar。构建时会从 Modrinth 获取最新的兼容 BBS FS 版本。
